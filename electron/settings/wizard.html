欢迎使用 Mayuka

Mayuka 是桌面悬浮角色。开始前需要两样东西：Live2D Cubism Core（运行库）和一个角色模型。它们都保存在本机，不会上传。

Cubism Core 请到 Live2D 官网下载 Cubism SDK for Web 后选择文件。

安装 Cubism Core

让 Mayuka 能够显示 Live2D 模型。

选择 live2dcubismcore.min.js，或整个 SDK 的 .zip。
